# SubsTracker

契約中のサブスクリプションサービスを一元管理し、利用料金を可視化する Web アプリケーションです。

---

## 動作環境

- Windows
- Python 3.x
- Web ブラウザ（PC・タブレット・スマートフォン対応）
- オフライン利用可能

---

## セットアップ

初回のみ、以下の手順でセットアップを行ってください。

1. `run_setup.bat` をダブルクリックして実行します。
   - Python の仮想環境（venv）が作成されます。
   - 必要なパッケージが自動的にインストールされます。

---

## 起動方法

セットアップ完了後、以下の手順でアプリを起動します。

1. `run_app.bat` をダブルクリックして実行します。
2. ブラウザで `http://localhost:5000` を開きます。

---

## 機能一覧

### ダッシュボード画面

アプリを開いたときに表示されるトップ画面です。登録済みサブスクリプションの集計情報を確認できます。

| 表示項目 | 内容 |
| --- | --- |
| 契約数 | 登録されているサービスの総件数 |
| 月額換算合計 | 全サービスの料金を月額換算した合計金額 |
| 年額換算合計 | 全サービスの料金を年額換算した合計金額 |
| カテゴリ別件数 | カテゴリごとの登録件数 |
| 最近追加したサービス | 新しく追加した順に最大3件を表示 |
| カテゴリ別支出 | カテゴリごとの月額換算・年額換算金額（月額換算の降順） |
| 年間コストランキング | 年間コストが高いサービスの上位5件 |
| 今後の支払予定 | 支払日が登録されている月額サービスを支払日昇順で表示 |
| 更新予定 | 更新日が登録されているサービスを更新日昇順で表示 |

### サブスクリプション一覧画面

登録済みのサブスクリプションを一覧表示します。

- サービスの新規登録
- サービス情報の編集
- サービスの削除（削除前に確認ダイアログを表示）
- CSV エクスポート（登録済みデータを CSV ファイルとしてダウンロード）
- CSV インポート（CSV ファイルからサービスを一括登録）

#### カテゴリフィルタ

カテゴリボタンをクリックすると、選択したカテゴリのサービスのみ表示されます。

#### ソート

以下の並び順を切り替えられます。

| 並び順 | 説明 |
| --- | --- |
| 作成日（新しい順） | 登録が新しいサービスを先頭に表示（デフォルト） |
| 作成日（古い順） | 登録が古いサービスを先頭に表示 |
| 料金（月額換算・高い順） | 月額換算金額が高いサービスを先頭に表示 |
| 料金（月額換算・安い順） | 月額換算金額が安いサービスを先頭に表示 |
| サービス名（昇順） | サービス名をアルファベット・五十音順で表示 |

## サービスの登録項目

| 項目 | 必須 | 説明 |
| --- | --- | --- |
| サービス名 | ✅ | サービスの名称 |
| 料金 | ✅ | 正の整数で入力 |
| 請求周期 | ✅ | 月額 または 年額 |
| カテゴリ | ✅ | 下記の固定カテゴリから選択 |
| 支払日 | — | 月額契約の場合に入力推奨（1〜31） |
| 契約開始日 | — | 契約を開始した日付（YYYY-MM-DD） |
| 更新日 | — | 契約の更新日（YYYY-MM-DD） |
| ステータス | ✅ | 利用中 / 停止中 / 解約済み |

### カテゴリ

以下の固定カテゴリから選択できます。

- 動画
- 音楽
- AI
- ゲーム
- 仕事
- クラウド
- その他

## 料金の集計方法

### 月額換算

| 請求周期 | 計算式 |
| --- | --- |
| 月額 | 料金をそのまま使用 |
| 年額 | 料金 ÷ 12 |

### 年額換算

| 請求周期 | 計算式 |
| --- | --- |
| 月額 | 料金 × 12 |
| 年額 | 料金をそのまま使用 |

---

## ステータスについて

| ステータス | 説明 |
| --- | --- |
| 利用中 | 現在契約中。集計対象に含まれます。 |
| 停止中 | 一時停止中。集計対象に含まれます。 |
| 解約済み | 解約済み。集計対象外ですが、履歴として保持されます。 |

## CSV エクスポート / インポート

### エクスポート

一覧画面の「CSV エクスポート」ボタンをクリックすると、登録済みの全サービスを CSV ファイルとしてダウンロードできます。

出力項目：サービス名 / 料金 / 請求周期 / カテゴリ / 支払日 / 契約開始日 / 更新日 / ステータス / 作成日時 / 更新日時

### インポート

一覧画面の「CSV インポート」ボタンをクリックして CSV ファイルを選択すると、サービスを一括登録できます。

必須列：サービス名 / 料金 / 請求周期 / カテゴリ

> エクスポートした CSV をそのままインポートファイルとして利用できます。
